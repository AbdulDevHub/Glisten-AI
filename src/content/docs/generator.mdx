# The generator

The generator turns a description into a single-file React component styled with Tailwind CSS.

## Starting a generation

You can start from:

- **A prompt:** describe the component or page, the content and the feel you want.
- **A reference image:** attach a screenshot or sketch for the layout to follow.
- **A critique:** press **Fix with AI** on a critique, and the generator receives the original image plus every issue to address.

## The preview

Code streams into the editor as it's written, and a live preview renders beside it. The preview runs in a sandboxed frame on a separate origin, so generated code can't reach your account or other pages.

## Iterating in chat

Ask for changes in plain language, such as "make the header sticky" or "use a two-column layout on desktop". Each tweak creates a new version, and you can step back to any earlier one.

## Exporting

- **TSX:** one component with Tailwind classes, ready to paste into a React or Next.js project that already uses Tailwind.
- **HTML:** a standalone file that loads Tailwind from a CDN, handy for quick prototypes.

## Good prompts

Be specific about content and constraints: "A pricing table with three plans, monthly/yearly toggle, dark background, the middle plan highlighted" works far better than "a pricing section".
