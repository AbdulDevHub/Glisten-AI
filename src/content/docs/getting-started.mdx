# Getting started

Glisten has two tools that share one workspace: the **critic**, which reviews a UI and pins its problems, and the **generator**, which writes React + Tailwind code. This guide walks through both.

## 1. Pick a plan

Every account needs either your own AI key or a paid plan:

- **BYOK (free):** add a Claude or OpenAI API key in settings. See [Bring your own key](/docs/byok).
- **Pro or Team:** hosted runs paid for with monthly credits. See [Plans and credits](/docs/credits).

## 2. Create a project

Projects group the critiques and generations for one product or page, and keep their version history together. Name it after the site or app you're working on.

## 3. Run a critique

Upload or paste a screenshot, or enter a URL. For URLs, Glisten captures the page at a desktop and a mobile width. In a few moments you get:

- **Pinned issues** on the image, each with a category, a severity and a suggested fix
- An **overall score**, so you can compare versions

Read more in [The critic](/docs/critic).

## 4. Fix with AI, or generate from scratch

Press **Fix with AI** on a critique to send its issues to the generator, or start a new generation from a prompt. The code streams into an editor with a live preview, and you can keep refining it in chat.

Read more in [The generator](/docs/generator).

## 5. Export

Copy the TSX into your React or Next.js project, or export a standalone HTML file.
