# Plans and credits

## Plans

| Plan | Price              | Hosted credits                       |
| ---- | ------------------ | ------------------------------------ |
| BYOK | $0                 | None. Runs use your own API key      |
| Pro  | $12 / month        | 200 per month                        |
| Team | $29 / seat / month | 200 per seat, pooled across the team |

Full details are on the [pricing page](/pricing).

## What things cost

| Action                       | Credits            |
| ---------------------------- | ------------------ |
| Critique (screenshot or URL) | 1                  |
| Generate a component or page | 2                  |
| Tweak a generation in chat   | 1                  |
| Max quality (Claude Opus)    | ×2 the normal cost |

Standard runs use Claude Sonnet. **Max quality** switches to Claude Opus for harder designs and costs twice as much.

## How credits are charged

Credits are deducted when a run starts. If the run fails on our side, they're refunded automatically.

## Renewal and top-ups

Monthly credits reset on your renewal date and don't roll over. If you run out mid-month, you can buy a top-up pack or switch to BYOK.

## Teams

On the Team plan, every seat adds 200 credits to a shared pool. Adding or removing seats updates the pool on the next billing cycle.
