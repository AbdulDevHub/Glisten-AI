# FAQ

## Is Glisten available yet?

Not yet. Glisten AI is in development, and these docs describe how it will work at launch. The [changelog](/changelog) tracks what has shipped.

## Who can see my uploads?

Only you, or your team on a Team plan. Uploads and generations are sent to the AI provider that processes the run (Anthropic, or OpenAI if you use an OpenAI key). See the [privacy policy](/privacy) for details.

## Do you train AI models on my designs?

No. Glisten doesn't train models. The AI providers we use don't train on API data by default; see their policies for details.

## How accurate is the critic?

It catches many common problems reliably (contrast, spacing, alignment), but it's an AI model and it can be wrong or miss context. Treat its pins as suggestions from a sharp reviewer, not as rules.

## Which frameworks does the generator support?

It writes React components styled with Tailwind CSS, which work in Next.js, Vite and other React setups. It can also export plain HTML.

## Can I use generated code commercially?

Yes. Code you generate is yours to use. See the [terms](/terms).
